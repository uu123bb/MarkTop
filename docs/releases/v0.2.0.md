## 本次变更

### 移除：即时渲染与沉浸模式

上一版有四种模式，其中「即时渲染（Vditor IR）」和「沉浸」都没达到可用水准，这一版直接删掉，只保留两种语义明确的形态：

| 模式 | 行为 |
| --- | --- |
| 双栏 | 左侧源码编辑，右侧实时预览 |
| 源码 | 单栏纯编辑，专注写作 |

- `Ctrl+E` 只在两者之间切换
- 打开旧配置时，`mode` 为 `ir` / `immersive` 会自动回落到 `split`，不会出现「打开就是空白」

顺带修掉一个真实缺陷：删 IR 时残留了一处 `destroyIr()` 调用，运行时抛 `ReferenceError` 导致模式初始化整段中断，表现是**编辑器在、预览区全白**。已修复，并补了 `window.onerror` 兜底——以后这类错误会直接弹提示，不再静默失败。

### 新增：GitHub 扩展语法

- **Alerts**：`> [!NOTE]` / `[!TIP]` / `[!IMPORTANT]` / `[!WARNING]` / `[!CAUTION]`，标题本地化为「注意 / 提示 / 重要 / 警告 / 危险」
  - 预览：深色底 12% 色调 + 3px 左色条，图标沿用 Lute 输出
  - 导出 HTML / PDF：GitHub 原色（`#ddf4ff`、`#dafbe1`、`#fbefff`、`#fff8c5`、`#ffebe9`）
- 任务列表、脚注、删除线、裸链接自动识别——Lute 原生支持，实测渲染正常

## 运行要求

- Windows 10 1809+ / Windows 11，x64
- WebView2 Runtime（Windows 10/11 随 Edge 自带；缺失时系统会自动提示安装）
- 首次启动约 3–5 秒（解压内嵌资源），之后 1 秒级

## 功能

- **两种编辑形态**：双栏（源码 + 实时预览）、源码（纯编辑）
- **多标签 + 文件树**：打开文件夹作为工作区，树懒加载，标签各自保留撤销栈与脏标记
- **IDE 风格深浅主题**：外壳、源码区、预览与代码高亮同步换肤
- **语法高亮**：Markdown / JSON / XML / YAML 语法树着色，其它文本按纯文本编辑
- **语法检查**：markdownlint 在 Web Worker 中运行，波浪线 + 行号槽标记，支持文档目录下的 `.markdownlint.json`
- **GitHub 扩展语法**：Alerts、任务列表、脚注、删除线、裸链接
- **公式与图表**：KaTeX、Mermaid 随包离线分发，零网络请求
- **导出**：Markdown、自包含 HTML（内联样式、KaTeX 字体 base64、Mermaid 转内联 SVG）、PDF（A4、可配置页边距、无页眉页脚）
- **导入**：HTML → Markdown，剥离 script/style/iframe 与内联事件后保留标题、列表、表格、代码、链接
- **图片**：粘贴或拖入落到文档同级 `assets/`，正文写相对路径
- **GitHub README 快速编辑**：克隆 `https://github.com/<用户名>/<用户名>.git`，保存即 `add → commit → push`，非快进自动 rebase 重试一次

## 已知限制

- 分发包不做代码签名（Authenticode），Windows 首次运行可能弹 SmartScreen，需「更多信息 → 仍要运行」
- 文件树仅支持懒加载与双击打开，无右键菜单（新建 / 重命名 / 删除）
- 语法检查的波浪线已接入，尚未逐条目视核对
