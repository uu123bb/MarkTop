# MarkTop v0.1.0

首个可用版本：Windows 10/11 上的本地化 Markdown 编辑器，单文件绿色发布，离线渲染。

## 运行要求

- Windows 10 1809+ / Windows 11，x64
- WebView2 Runtime（Windows 10/11 随 Edge 自带；缺失时系统会自动提示安装）
- 首次启动约 3–5 秒（解压内嵌资源），之后 1 秒级

## 功能

- **三种编辑形态**：双栏（源码 + 实时预览）、沉浸（无干扰单栏）、即时渲染（Vditor IR，编辑处即排版效果）
- **多标签 + 文件树**：打开文件夹作为工作区，树懒加载，标签各自保留撤销栈与脏标记
- **IDE 风格深浅主题**：外壳、源码区、预览与代码高亮同步换肤
- **语法高亮**：Markdown / JSON / XML / YAML 语法树着色，其它文本按纯文本编辑
- **语法检查**：markdownlint 在 Web Worker 中运行，波浪线 + 行号槽标记，支持文档目录下的 `.markdownlint.json`
- **公式与图表**：KaTeX、Mermaid 随包离线分发，零网络请求
- **导出**：Markdown、自包含 HTML（内联样式、KaTeX 字体 base64、Mermaid 转内联 SVG）、PDF（A4、18 mm 页边距、无页眉页脚）
- **导入**：HTML → Markdown，剥离 script/style/iframe 与内联事件后保留标题、列表、表格、代码、链接
- **图片**：粘贴或拖入落到文档同级 `assets/`，正文写相对路径
- **GitHub README 快速编辑**：克隆 `https://github.com/<用户名>/<用户名>.git`，保存即 `add → commit → push`，非快进自动 rebase 重试一次

## 数据位置

| 内容 | 位置 |
| --- | --- |
| 配置 | `MarkTop.exe` 同目录 `setting-marktop.json`（唯一写在 exe 旁的运行时文件） |
| web 资源缓存 | `%LOCALAPPDATA%\MarkTop\web\<hash>` |
| WebView2 用户数据 | `%LOCALAPPDATA%\MarkTop\WebView2` |
| GitHub 仓库克隆 | `%LOCALAPPDATA%\MarkTop\repos\<用户>\<用户>` |
| 日志 | `%LOCALAPPDATA%\MarkTop\logs\app.log` |

## 已知限制

- 依赖系统 WebView2 运行时，无法在单文件内固定运行时版本
- 导出 HTML 中正文图片仍使用相对路径（依赖与文档同级的 `assets/`）
- `.lang` 按无语法定义的语言文件处理（纯文本 + 括号匹配）
- 文件树暂不支持右键新建/重命名/删除

## 验证

```
MarkTop.exe --self-test .\selftest
```

覆盖：打开文档 → WebView2 回读全文 → 导出 Markdown / HTML / PDF → 多标签切换。全部通过时退出码为 0。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+O` / `Ctrl+S` | 打开 / 保存 |
| `Ctrl+E` | 双栏 / 源码 / 沉浸 / 即时渲染 轮换 |
| `F11` / `Esc` | 进入 / 退出沉浸模式 |
| `Ctrl+F` / `Ctrl+H` | 查找 / 替换（源码区） |
